# Room planner

This project started out as a mini-project for an application, but grew into a prototype that will be implemented in Regncons 2025 version of its [webpage](https://github.com/Regncon/conorganizer). I've often seen products like this when going to shopping centre kiosks and wanted to give it a shot making my own version.

## Why?

The goal is to explore how floor plans, rooms, and architectural layouts can be represented as structured geometry data and rendered dynamically in the browser without relying on heavy external libraries.

## Want to test this code?

First you have to install [Nodejs](https://nodejs.org/en/download), then you can run the Nextjs development server:

1. Install all dependencies for the project

```bash
npm install
```

2. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
